<h2>Short Explanation</h2>

A linked list is a data structure where elements are stored in the form of nodes. Each node stores some data and a link to the next node. The first node is accessed using the head of the list. Unlike an array, the nodes in a linked list do not need to be stored next to each other in memory. We can move through the list one node at a time using the next reference.

In this assignment, I implemented a simple singly linked list and performed operations such as adding and deleting nodes from the beginning and end of the list. I also implemented searching for a value and deleting a particular value .
<h2>Methods Implemented</h2>

<h3>Methods</h3> 

addFirst(value) — Adds a new node at the beginning.

addLast(value) — Adds a new node at the end.

deleteFirst() — Deletes the first node.

deleteLast() — Deletes the last node.

print() — Displays all nodes in the linked list.

find(value) — Searches for a value and returns true or false.

delete(value) — Deletes the first node containing the given value.
